# R1 Toolbox

专为海康R1 & R1X 刷飞牛后的硬件问题修复与功能增强。

## 功能特性

### 小屏界面
- 🎛 控制中心（亮度、息屏、RGB灯效、风扇模式、主题切换）
- 🌤 时钟天气
- 📊 资源监控
- 👆 完美触控
- 🎨 主题更换
- 🎬 动态视频壁纸
- 🎵 音乐播放器（黑胶唱片）
- ⏰ 定时亮灭屏
- 📜 自动滚屏

### Web管理
- ⚙️ 功能设置（RGB灯效、屏幕亮度/息屏/定时、风扇控制）
- 📈 实时监控（CPU温度/使用率、内存、硬盘温度、风扇转速）
- 🌡 风扇曲线（自定义温度-转速曲线，智能温控）
- 🖌 主题编辑（可视化编辑器，模块拖拽、样式调整、配色调整）
- 🎶 音乐播放器（黑胶唱片、歌词动画、web声卡双输出、蓝牙媒体键控制）

### 其他功能
- 🔧 MAC地址修复（自动检测双网口生成新MAC地址）
- 🎥 视频壁纸更换
