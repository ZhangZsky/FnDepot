# R1 Toolbox

适配 x86\_64 / ARM64 双架构，影音直出可选，不限机型同时优先支持海康R1 / R1X 及同源方案等个设备。

## 功能特性

### 小屏界面（需带屏设备）

- 🎛 控制中心（亮度、息屏、RGB灯效、风扇模式）
- 🎵 音乐播放器（黑胶唱片）
- 🎬 动态视频壁纸

### Web管理

- ⚙️ 功能设置（RGB灯效、屏幕亮度/息屏/定时、风扇控制）
- 📈 实时监控（CPU温度/使用率、内存、硬盘温度、风扇转速）
- 🌡 风扇曲线（自定义温度-转速曲线，智能温控）
- 🎶 音乐播放器（黑胶唱片、歌词动画、web声卡双输出、蓝牙媒体键控制）

### PipeBridge 联动

- 🖥 HDMI 音频输出
- 📡 配合 PipeBridge 蓝牙音箱播放音乐
- 🎚 多设备同播、按流路由，HDMI 与蓝牙同步出声

### 其他功能

- 🎥 视频壁纸更换（B站视频教程）
- 🔧 MAC地址修复
